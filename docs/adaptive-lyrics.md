# 随机样式与收藏预设

播放器外观区、外观设置和歌词预览共用随机外观控件。从左到右依次为「全随机开关」文字、范围开关、「随机样式」按钮和收藏星星。

## 切歌随机

外观设置中的「切歌随机」默认关闭。只有显式开启后，每次显示歌曲切换才随机选择一个可用歌词动画，并随机动画参数，候选有多个时避开当前模式。手动选择模式后，本首歌保持你的选择。点击「随机样式」或应用收藏预设会关闭切歌随机和旧的随机模式开关，随后切歌继续沿用这组设置；需要每首重新随机时，可再次显式开启「切歌随机」。

随机选择无需音频采样、歌词加载或 IndexedDB。队列下一首会提前选定模式并预加载渲染器代码；转场仍显示旧歌曲时继续使用旧样式，画面交接后才应用下一首结果。减少动态效果与壁纸模式限制候选为较平缓的模式，手动随机也遵循相同限制。

## 随机范围与立即随机

「全随机开关」默认关闭。关闭时只随机歌词动画模式及其参数，通用字体、字号、字重、透明度、独立背景模式和参数、URL 资源及封面取色偏好均保持原值。开启后才同时随机通用、背景和歌词动画设置。范围开关会记住上次选择，并随外观配置导入导出和设置同步；切换范围本身不会改变当前画面，也不会开启「切歌随机」。

切歌随机与「随机样式」按钮使用同一个范围。点击按钮即可立即生成并保存一组设置，无需歌曲正在播放。结果在切歌、暂停和重启后继续使用，直到再次点击随机、手动修改设置或应用其他预设。手动修改只更新指定设置，其余值保持不变。数值在各设置的合法范围内随机；上传资源与 URL 只使用已有资源，随机不会删除资源或凭空创建资源地址。

字幕及和声字幕的设置保持原值。字幕如果继承歌词字体，歌词字体变化仍会影响继承后的显示效果。

## 收藏预设

行末空心星星用于保存当前外观。收藏后变为黄色，再次点击可取消收藏；实际执行随机后会恢复空心状态，单独切换随机范围不会取消收藏。收藏预设保存通用、背景、歌词动画、字幕设置及 Folium 模组的视觉参数，按本地用户配置持久化，重启后仍可使用。

预览设置右上方的「收藏预设」页列出收藏；点击卡片即应用，可通过卡片的删除按钮移除。点击铅笔按钮可修改预设名称，按 Enter 或勾选按钮保存，按 Esc 或取消按钮放弃。名称不能为空，首尾空格会自动去除；修改名称只更新收藏标签，不改变当前外观。名称随本地收藏、JSON 与短码备份保存，重启后保留。

应用只恢复当时选中的背景 URL，其他 URL 后来的编辑保持原值；模组的业务设置不随外观收藏改变。旧格式收藏继续可用，未保存模组参数的旧收藏保留当前模组参数。外观配置的 JSON 与短码备份包含收藏列表。上传图片、头像和字体仍使用现有本地资源；更换或删除对应资源后，旧收藏不能恢复已删除的文件内容。

实现入口：`src/services/visualStylePresets.ts`（快照、应用、随机）、`src/stores/useFavoriteVisualPresetsStore.ts`（收藏）、`src/hooks/useAdaptiveLyrics.ts`（每首随机）。
